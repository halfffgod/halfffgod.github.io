# Nare Badalyan — Data Analytics Portfolio

## Publish on GitHub Pages
1. Download and unzip this package.
2. Open `https://github.com/halfffgod/halfffgod.github.io`.
3. Choose **Add file → Upload files**.
4. Upload `index.html`, `style.css`, and `README.md` to the repository **root** (not inside `react-portfolio`).
5. Commit the changes to `main`.
6. In **Settings → Pages**, choose **Deploy from a branch**, branch `main`, folder `/(root)`.
7. Wait a few minutes and visit https://halfffgod.github.io.

## Important: churn project link
The Telecom Customer Churn card currently links to your GitHub repositories page because the exact churn repository URL was not available. In `index.html`, replace both instances of:
`https://github.com/halfffgod?tab=repositories`
with the exact URL of your churn repository when you have it.

## Customize
- Edit text and links in `index.html`.
- Change colors, spacing, and layout in `style.css`.
- The dashboard-like visuals are CSS illustrations, not screenshots of your actual reports. Replace them with genuine screenshots later if you want.
- This is a static HTML/CSS website; no React, Node.js, terminal, or build step is required.
